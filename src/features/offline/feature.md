# Feature: 📴 Local-First 離線模式與 PWA 斷網快取 (Offline Mode & Resilient Sync)

## 1. 模組定位與功能概述 (Module Overview)
本模組提供使用者在無網路連線（地下室、飛行模式、網路不穩）或主動開啟離線模式時，能 100% 完整操作看板、收件匣、卡片建立、編輯、刪除、拖曳排序、搜尋、Markdown 筆記與 Checklist 子任務，並具備：
1. **Local-First 零阻斷操作**：所有狀態變更即時存入本地持久層（LocalStorage），無網路阻塞。
2. **離線變更佇列（Pending Sync Queue）**：離線期間的每次操作記錄進入佇列，統計待同步筆數。
3. **動態離線視覺指示**：頂部 Navbar 離線狀態徽章膠囊、頂部柔和滑入式 `OfflineBanner` 離線提示列。
4. **自動連線重試與無縫合併**：自動監聽 `online` 事件，連線恢復時背景自動批次同步至 Firestore 雲端，並以 Last-Write-Wins 演算法安全合併。
5. **本機 NLP 降級備援**：離線時文字速記由 Local NLP 正規表達式引擎精準解析，建立帶有「⚡ 離線本機解析」標註之結構化卡片。
6. **設定中心開關**：支援在「系統設定」與使用者選單中手動啟用/關閉「離線工作模式」。
7. **PWA Service Worker 強健快取**：預先快取應用外殼與靜態檔案，即使在完全斷網下重新整理網頁亦可平滑啟動。

## 3. UI 5 種狀態規範 (5 UI States)
1. **Loading**：網路恢復時自動觸發「正在同步離線變更...」旋轉動畫與進度狀態。
2. **Empty**：無待同步離線資料且處於正常連線時，不顯示侵入性橫幅，狀態顯示「雲端已同步 / 最新」。
3. **Error**：離線同步重試失敗時，提供「同步異常・點擊手動重試」按鈕與明確中文提示，絕不丟失本地資料。
4. **Success**：連線恢復並成功將離線變更同步至雲端後，彈出 Toast「已恢復連線，雲端資料同步完成」並隱藏離線橫幅。
5. **Active / Interactive**：離線橫幅支援「立即重試」、「切換連線」與「關閉提示」等微互動操作。
