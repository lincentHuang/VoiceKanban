# 🔍 Search Feature (全域響應式搜尋模組)

## 1. 模組簡介
Search 模組提供全應用程式的即時任務關鍵字與標籤過濾功能。
本模組提供 Command Palette / Spotlight 風格的搜尋彈窗（`SearchModal`），結合全響應式觸發設計：
- **桌機版（`≥ sm`）**：以頂部美觀之快捷觸發欄呈現，支援鍵盤 `⌘K` / `Ctrl+K` 快速呼叫。
- **手機版（`< sm`）**：在 Header 右側頭像旁提供精緻圓角搜尋圖示按鈕，防止搜尋列在窄螢幕下被擠壓壓縮。

## 2. 核心功能與互動
- **即時模糊過濾**：跨看板與收件匣過濾任務標題、內文描述與 `#標籤`。
- **UI 5 種狀態嚴格遵循**：
  1. **引導狀態**：未輸入關鍵字時呈現常用標籤快速填入與置頂星號任務。
  2. **無相符結果狀態 (Empty)**：顯示友善引導插圖與建議。
  3. **加載狀態 (Loading)**：平滑微動畫切換。
  4. **相符清單狀態 (Success)**：呈現所屬欄位色標、標籤、截止日期與優先級星號。
  5. **選取狀態 (Active)**：支援鍵盤 `↑` / `↓` 導航高亮切換。
- **深層聯動**：
  - 按下 `Enter` 或滑鼠點擊任意搜尋結果，直接開啟該任務詳細編輯面板（`setEditingTaskId`）。
  - 提供「在看板套用」按鈕，可將關鍵字同步至全局看板過濾條件（`searchQuery`）。
  - 提供「清除看板篩選」快捷按鈕。
